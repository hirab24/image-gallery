# 🖼️ Pixel Gallery

A modern and responsive **Image Gallery** built with **HTML, CSS, and JavaScript**. This project features a clean UI, category filtering, fullscreen lightbox, dark mode, and smooth user interactions.

---

## ✨ Features

- 🎨 Modern & Responsive Design
- 🌙 Dark / Light Mode
- 🖼️ Interactive Image Gallery
- 🔍 Category Filter
- 💡 Fullscreen Lightbox
- ⬅️ Previous / Next Navigation
- ⌨️ Keyboard Navigation (Arrow Keys & ESC)
- ✨ Smooth Hover Animations
- 📱 Mobile Friendly

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/hirab24/image-gallery.git
```

### Open the project

```bash
cd image-gallery
```

Run **index.html** in your browser or use the **Live Server** extension in VS Code.
